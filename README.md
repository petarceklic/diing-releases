# Diing

Downloads for [Diing](https://extravowel.com/diing), a free menu bar app for Ring cameras on the Mac, made by [Petar Ceklic](https://petarceklic.com).

Get the latest version from [Releases](https://github.com/petarceklic/diing-releases/releases/latest):

- **Apple Silicon** (M1 and later): `Diing-<version>-arm64.dmg`
- **Intel**: `Diing-<version>-x86_64.dmg`

Needs macOS 14 or later. Every build is signed with Developer ID and notarised by Apple, and Diing updates itself after that.
